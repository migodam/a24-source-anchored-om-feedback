# 来源与公开范围

- `vendor/a2/physics.py` 是用户已有 A2 研究代码的原样快照。
- `src/a20`、`vendor/a17/a9_engine.py` 来自已公开 A23 commit
  `a47cda424dfb55792e69d952a25f54ce9a2a5613`，后端历史 pin 为
  `b85a29a51f4ea7b4d93617e827d88e23933b89df`。
- `theory/` 是 A24 交付研究包的保留副本，历史验证和拟定配置不等于本仓库实验。
- NumPy/SciPy/Matplotlib 使用现有安装，不打包第三方运行环境、论文全文或凭据。
- A24 新实验代码与证据由本仓库记录。没有因为理论正确或测试通过而自动认定成像收益。
- 公开 metadata 将本机绝对路径转换为仓库相对路径；原本机 metadata 保留在
  ignored private 目录。所有数值、counter、时长和失败原文类型保持原值。
  大型逐事件账本以 gzip/Release 保存，不删除事件、不重新定义费用。
